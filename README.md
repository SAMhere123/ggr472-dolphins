# Dolphin Watching in Hawaii for the Ethical Tourist
This repository contains code for a webpage with an interactive map through Mapbox GL JS

Webpage: https://samhere123.github.io/ggr472-dolphins/index.html

## Key repository contents
- `Data folder` : Data file containing point locations, migration, temperature, and photos/video of dolphins
    - `dolphins-data.js` : JavaScript file containing geoJSON of dolphin sighting data
- `index.html` : HTML file to render homepage
- `style.css` : CSS file to control style of homepage
- `script.js` : JavaScript file to enable button interactivity within homepage
- `donate_button.js` : JavaScript file to enable donate button interactivity within Conservation page
- `species.html` : HTML file containing information on dolphin species
- `Threats.html`: HTML file containing information on threats to dolphin species
- `Conservation.html`: HTML file containing information on conservation efforts for dolphin species
- `SustainableWatching.html`: HTML file containing information on sustainable dolphin watching
